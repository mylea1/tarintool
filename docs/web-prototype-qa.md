# Web 高保真原型验收记录

日期：2026-08-01

## 已验证流程

- 今日训练进入训练进行页，无需刷新
- 完成正式组后自动启动休息计时，剩余时间由 `targetEndAt` 计算
- 休息暂停、恢复、增加 15 秒、跳过及设备界面同步展示
- 已完成历史组锁定重量、次数、组类型与休息快照；仍可显式撤销完成
- 批量模式只允许选择未锁定组，并支持重量/次数增量
- 动作库已提升为训练页固定分栏，支持搜索、肌群/器械筛选、动作详情和素材缺失状态
- 训练计划卡、日历训练内容与计划详情均从动作库读取图片和名称
- 识别流程覆盖待上传、处理中、正常报告、低置信度和离线状态
- 识别报告将主要动作、耦合支撑、稳定性和证据质量分开呈现
- AI 与识别保持独立入口；训练摘要需授权，回答展示来源引用
- 官方计划详情、计划生成草案和上次训练转计划入口可用
- 进步页展示长期目标、肌群分布、周热力图和动作趋势
- 灵动岛、锁屏、Android 通知和 Watch 仅作为设备能力模拟，不声称 Web 原生支持

## 浏览器与布局

| 宽度 | 结果 |
| --- | --- |
| 320 | 无水平滚动；训练组行可完整操作 |
| 375 | 无水平滚动；AI、训练、进步和计划详情可用 |

## 当前阶段边界

- 这是本地交互验证原型，不是正式 Web 产品。
- 识别进度、AI 回答、官方内容下载和设备系统界面为模拟数据。
- 11 组动作插图复用许可明确素材，其余动作显示统一占位状态。
- 尚未完成 8–12 名目标用户任务测试，因此 `contracts/` 和 Flutter 生产业务层暂不冻结。
- 真实识别准确率、关键错误 F1、临时视频删除和无状态 API 需要在后端质量门槛阶段验证。
