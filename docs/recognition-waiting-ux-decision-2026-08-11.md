# 动作识别等待态决策

- 目标用户：训练结束后上传短视频、希望快速确认动作质量的健身用户。
- 当前替代方案：盯着静态文字等待，失败后无法判断是视频、网络、排队还是 Worker 问题。
- 最小可用路径：选视频并预览 → 开始分析 → 明确看到上传、排队、分析阶段 → 查看结果或带原因重试。
- 页面主动作：完成一次可理解、可恢复的识别任务。
- 核心指标：识别任务完成率、重复提交率、失败后重试成功率。
- 失败损失：用户误以为应用卡死，重复消耗额度或直接放弃识别功能。

设计读取：原生健身工具；训练后单手操作用户；暖橙、清晰、可信；Material 3 与 Apple HIG；视觉密度 6、动效强度 6、布局变化 4。

不使用虚假的百分比进度。上传阶段显示真实字节进度，排队与分析阶段显示持续动效、已等待时间和阶段说明；减少动态效果时保留静态高对比状态。
