# 主页、导航、好友与个人页调整

目标版本：Android 1.0.34（36）。

## 功能调整

- 底部导航改为主页、记录、动作、AI、我的。右侧独立圆形训练入口进入训练计划或继续正在进行的训练；记录页与实时训练独立。
- 实时训练 AI 使用圆形悬浮按钮，长按拖动，位置限制在页面安全范围内。删除额外的整条底部占位，避免出现第二条导航的视觉效果。
- 从历史训练复制的动作/组备注与上次一致时，不自动填入本次备注；历史备注保留在上次备注区域。独立的新计划提示和当前已编辑备注保留。
- 好友动态中文展示分钟、训练量、组数，删除重复指标行。动作列表显示每个动作的组数，点赞/表情在成果图片卡片之外，按正常触控尺寸显示。
- 账号新增十位数字公开 ID。服务端随机分配、唯一索引约束、持久化；原内部用户 ID、登录 identifier、手机号身份表及好友关系保持不变。手机号继续完整匹配搜索。旧 Apple 机器标识不再显示为默认昵称。
- 签到入口与接口保持停用，未恢复签到奖励。
- 主页“今日安排”显示简短状态、动作数/完成组数和一个开始/继续入口，推荐理由折叠，保留本周肌群与饮食入口。右上角增加好友入口。
- 我的页面顶部为头像、用户名和数字 ID；会员独立图片卡分别呈现开通入口、已开通状态与到期信息。
- 成果列表与分享海报使用动态高度，避免动作列表被固定画布裁切。

## 服务端发布

线上原版本：`/opt/kilo/releases/01e30fa-sms-20260905T0008`。
本次发布：`/opt/kilo/releases/navigation-id-20260905`。

线上与仓库主分支存在先前差异，因此只在原线上副本增加数字 ID 迁移、公开字段与昵称清理，没有直接覆盖整个主分支后端。精确补丁记录在 `docs/deployments/2026-09-05-public-account-id.patch`。

发布前通过服务器副本全部 59 项测试，使用 SQLite 在线备份保存至 `/var/lib/kilo/kilo-before-public-id-20260905.sqlite3`，随后原子切换 `/opt/kilo/current` 并重启 `kilo-api`。健康检查返回 200。迁移核对 12 个账号均有唯一、合法的十位数字 ID；未输出任何个人账号数据。

如需回退应用逻辑，将 current 指回原 release 后重启服务。新增字段属于兼容性迁移，通常无需恢复数据库；不要随意覆盖迁移后产生的新业务数据。
