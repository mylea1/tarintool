# 炽练 EMBER：训练闭环与视觉反馈方案

## 商业判断

本轮界面最需要改善的指标不是页面停留时长，而是“进入自由训练后，成功开始计时并记录第一组”的完成率。普通用户 `123/123` 用于验证真实受限体验，管理员 `1234/1234` 只承担后台验收，二者不能混用。

## 设计读取

- 页面类型：训练记录工具型移动应用
- 目标用户：需要边练边记、注意力被器械和休息打断的力量训练者
- 视觉语气：温暖、活跃、克制的力量感
- 审美家族：Apple 的清晰层级 + Material 的状态反馈，品牌色为暖橙与深咖
- 视觉密度：6/10；动效强度：8/10；布局变化：中等

## 最小使用路径

1. 登录后直接进入训练概览。
2. 点击“自由训练”，先进入准备态，不自动计时。
3. 用户可以先加动作，也可以直接点击“开始计时”。
4. 完成一组时，该组整体转绿，粒子从完成按钮附近爆发，底部只出现短时深色反馈胶囊。
5. “结束并保存”始终使用高对比的独立按钮，避免与工具按钮混淆。

## 关键改动

- 品牌由 KILO 的单字母占位升级为“炽练 EMBER”，火焰杠铃图形代表持续训练和力量增长；Bundle ID 保持不变。
- 登录首屏改为顶部品牌、单张登录卡与两个紧凑测试入口，移除占据半屏的 K 色块。
- 日历排程提供胸、背、肩、腿、手臂、核心、全身快捷选项，同时保留自定义名称。
- 动作库左侧分类不再使用厚重整列边框；选中态使用浅橙底、细描边与左侧强调线。
- 备注输入弹层随键盘上移，输入区保持可滚动，保存按钮不被遮挡。
- 锁屏与灵动岛显示训练总时长、当前动作和动态组间倒计时；倒计时用结束时间渲染，不依赖每秒推送固定数字。

## 可访问性与验收

- 所有主要触控目标至少 44×44。
- 状态不能只靠颜色：完成组同时显示勾选图标与文字反馈。
- 支持系统“减少动态效果”；粒子动画在该模式下退化为静态高亮。
- 预览需在 320、375、414、768、1024、1440 宽度检查溢出、键盘遮挡与弹层边界。
