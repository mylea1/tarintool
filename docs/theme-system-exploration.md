# KILO 五主题视觉探索

## 产品判断

目标用户是希望在训练现场快速完成记录，同时能回看进步、查询动作和使用 AI 建议的个人力量/增肌训练者。现有替代方案通常是 Hevy/训记类记录工具、手机计时器和聊天 AI 的组合。KILO 的最小可用路径应始终是：开始训练 → 完成一组 → 清楚看到休息与完成反馈 → 保存并查看总结。

主题不能改变信息架构，也不能让装饰挤占训练数据。五套方案共享“主页、训练、动作、AI、我的”导航、同一组状态颜色语义、同一触控尺寸与同一内容优先级，只替换设计 token、材质、插图和反馈表现。

商业判断：这组设计最可能影响训练开始率、组完成率与训练保存率；训练页中醒目的当前动作、整行完成反馈和单一主操作负责推动这些指标。

## 固定信息架构

1. 主页：今日训练、训练周、最近进步、继续训练。
2. 训练：训练/记录顶部切换，实时计时、组间休息、动作组表格、历史记录。
3. 动作：左侧部位筛选、搜索、双列动作卡、教学入口。
4. AI：AI 对话/动作识别顶部切换、来源引用、识别报告入口。
5. 我的：账号与会员、训练偏好、语言、通知与隐私。

## 设计旋钮

- `DESIGN_VARIANCE: 8/10`：主题差异明显，但布局与交互契约稳定。
- `MOTION_INTENSITY: 6/10`：完成组、保存训练和切换视图有短促反馈；支持 reduced motion。
- `VISUAL_DENSITY: 5/10`：训练表格保持紧凑，主页与详情保留呼吸空间。

## 交付约束

- 主要按钮每个阶段只保留一个。
- 完成状态不能只依赖颜色，必须同时有勾选图标和状态文字。
- 320–414px 宽度下不得横向溢出，长中文标题和数值增长时必须折行或截断。
- 主题切换不得改变数据、路由、埋点、表单字段或可访问性语义。
