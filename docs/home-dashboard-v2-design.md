# 主页仪表盘 V2 设计说明

## 产品判断

主页只回答三个高频问题：今天练什么、本周是否保持训练、同一个动作是否进步。它不再承担训练入口大全，因此移除了“训练概览”“实时训练”“自由训练”和最近记录列表。最可能改善的指标是从打开 App 到开始计划训练的完成率；首屏唯一主按钮负责推动这个指标。

## 竞品取舍

| 参考产品 | 借鉴内容 | 未照搬内容 |
| --- | --- | --- |
| Strong | 训练记录主路径简短、首要动作明确 | 不使用纯工具式黑白首页 |
| Fitbod | 今日训练计划与个体数据结合 | 不在主页堆叠恢复建议和大量推荐理由 |
| JEFIT | 肌群分布和可追踪的数据反馈 | 不使用高密度仪表盘与多个同级入口 |
| Hevy | 训练完成反馈和个人趋势 | 好友动态不进入主页首屏 |

## 页面结构

1. 今日训练：只展示当天安排或正在进行的训练；无安排时引导选择计划，不直接开始自由训练。
2. 本周训练：用七日状态和 `已完成天数 / 4 次` 提供轻量一致性反馈。
3. 本周肌群：按真实已完成组数绘制正反面热力图。
4. 动作趋势：从真实历史中选择任意有重量记录的动作，展示最近六次最大完成重量和与上次差值。
5. AI 定制训练：作为二级入口，在当前页面打开独立弹层，不跳转聊天页。

## 数据边界

- 不把最近一次训练冒充“今日训练”。
- 没有同动作历史时显示“首次记录”或空态，不制造趋势。
- 不比较不同动作、不同用户的绝对重量。
- 本周肌群仅统计标记为已完成的训练组。

## 响应式与可访问性

- 320dp 使用单列肌群/趋势卡；375dp 及以上使用双列。
- 所有主按钮保留至少 48dp 触控高度。
- 长计划名和动作名使用最多两行或单行省略，不推动卡片横向溢出。
- 动作趋势选择器使用底部弹层，支持清晰返回和当前项勾选。
- 热力图不能只依赖颜色，卡片底部同时显示主要肌群文本。

可交互预览位于 `design-previews/home-dashboard-v2.html`，包括开始训练、动作趋势切换和 AI 定制弹层。
