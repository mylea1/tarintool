# 训练进行中记录交互 V4

## 商业与用户任务

- 目标用户：正在训练、注意力和单手操作能力都有限的力量训练者。
- 核心任务：完成一组后立即记录重量、次数、备注并进入休息；从锁屏返回时继续同一训练。
- 关键指标：完整训练记录率、漏记休息次数、误操作恢复率、训练中途退出率。
- 失败成本：休息节奏被打断、完成组数据不可纠错、备注丢失，以及从锁屏返回后找不到训练导致放弃记录。

## 方案取舍

### 方案 A：完成即锁定

完成组后锁定输入，只允许取消完成再编辑。状态最明确，但增加纠错步骤，不符合训练现场的快速记录需求。

### 方案 B：完成但可编辑（采用）

完成组仍保持绿色成功态，重量、次数、类型和备注继续可编辑；删除需要确认。兼顾强反馈、纠错效率与误删保护。

### 方案 C：统一进入“编辑模式”

整张动作卡切换编辑态后才能修改。适合批量编辑，但训练现场操作成本过高。

## 交互规格

1. 自由训练新增动作时预置全局默认休息时间；历史脏数据或热身组休息为 0 时，热身组回退 60 秒，普通组回退全局默认值。
2. 动作备注固定显示在动作标题下方；每组备注固定显示在组行下方。空态也有明确“点击添加”入口。
3. 已完成组保持绿色状态，但重量、次数、组别类型和备注均可直接修改。
4. 每组提供删除按钮；已完成组删除前明确提示会影响训练统计。
5. iOS Live Activity 使用 `ember://training`，Android 通知使用 `OPEN_WORKOUT` intent；冷启动和热启动都通过平台通道导航至正在进行的训练。

## 视觉读取

页面类型为原生移动训练工具，采用现有暖橙品牌色、成功绿和低对比纸张底色。视觉密度 7/10，动效强度 4/10，布局变化 3/10。优先保证疲劳状态下的可识别性与触控稳定性。
