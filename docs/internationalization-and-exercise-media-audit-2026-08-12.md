# 形域国际化与动作媒体审计

日期：2026-08-12  
版本：1.0.11 (12)

## 用户可见改动

- “我的 → 个性化”中的原“动作语言”升级为“应用语言”。
- 支持简体中文和 English，选择会持久化到本机。
- 底部导航、页面标题、核心训练流程、动作库、AI、识别与设置中的高频文案随应用语言切换。
- 动作名称随应用语言切换；向 AI 发出的请求包含 `locale`，服务端按所选语言回答。
- 英文模式继续沿用同一套暖橙品牌与信息架构，不创建功能不同的海外分支。

## 中文重名审计

数据集共 1,324 个动作。原中文名由英文动作名称的词组映射自动生成，审计发现：

- 原始英文数据自身有 6 组完全重名记录。
- 自动中文翻译产生 137 组重名，涉及 233 条额外重复记录。
- 典型问题包括不同俯卧撑变式都显示为“俯卧撑”，以及未收录词被丢弃后回退成笼统名称。
- 连字符过去未被当作词边界，`close-grip push-up` 等名称会丢失关键限定词，现已修复。

现在动作库会保留简洁中文名；仅在发生冲突时附加英文变体与稳定数据集 ID。因此所有中文展示名称唯一，同时不改变训练记录、媒体与后端使用的动作 ID。

## 图片 / GIF 映射审计

审计脚本：`scripts/audit_exercise_media.py`

验证方法：按每个稳定数据集 ID 读取 JPG 与 GIF 第一帧，统一缩放后计算归一化平均绝对像素差。

- 成功配对：1,324 / 1,324
- 缺失：0
- 中位差：0.000682
- 最大差：0.001603
- 失败阈值：0.01

结论：当前 reference JPG 与教学 GIF 没有索引错位。用户感知到的“图片不匹配”主要由中文重名和过度简化造成，而不是媒体文件串位。
