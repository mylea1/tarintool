# 形域角色成长与世界功能设计

## 商业与用户判断

目标用户是已经把形域当作训练记录工具使用、但容易因短期进步不明显而中断记录的力量训练者。现有替代方案是单纯查看容量、PR 和连续训练天数；它能准确记录，却不能把长期积累变成持续可见的情绪奖励。

最小可用路径是：**开始训练 → 完成真实训练 → 获得基于自身历史进步的成长 → 在结算页看到角色与肌群变化 → 回到下一次训练**。首页的首要可衡量动作仍是“开始/继续训练”，游戏化主要影响训练完成率、次周留存和连续记录率，不能增加开始训练前的操作成本。

## 方案选择

### A. 只做本地角色与经验

成本最低，但“世界”没有真实同场关系，容易退化为孤立的装扮页；不采用。

### B. 本地优先成长 + 隐私保护的训练场服务（采用）

- 角色、等级、肌群、探索任务和结算本地持久化，离线训练不受影响。
- 服务端只保存用户主动选择的场馆代号、匿名昵称、训练部位、时长和在线过期时间。
- 不上传经纬度，不开放陌生人自由文本，不生成虚假在线用户。
- 今日回声来自真实到访事件；无人时显示真实空状态和引导，不伪造“4 位训练者”。

这个边界能验证留存价值，同时把隐私与内容治理成本控制在第一版可承受范围。

### C. 完整多人经济与社交系统

包含好友图谱、聊天、交易和排行榜，偏离专业训练主任务且带来审核、骚扰和作弊风险；第一版不采用。

## 信息架构

底部导航调整为：`首页 / 训练 / 世界 / AI / 我的`。动作库不删除，移动到训练页内的明确入口。世界页使用“训练场 / 探索”同级切换；好友能力保留数据边界，不在第一版首屏占位。

首页顺序：

1. 今日训练主卡与开始/继续训练（唯一主 CTA）。
2. 紧凑角色成长卡（角色、训练者等级、XP、主要肌群）。
3. 今日支线与训练场状态（次级入口）。
4. 原有训练周、进步和最近记录。

训练页保持现有密度。完成一组只显示 900ms 左右的轻反馈；结算页承担等级提升、肌群经验、奖励和角色变化的强反馈。

## 视觉读取

- 页面类型：现有 Flutter 健身产品的保留式增强。
- 用户：重视训练数据、又需要长期激励的力量训练者。
- 视觉语气：浅色暖橙、专业、克制、有少量游戏生命力。
- 设计家族：现有 Material 3 组件 + Apple HIG 的清晰层级与原生反馈。
- 变化程度：4/10；动效：4/10；密度：6/10。

角色使用同一暖橙、奶油白、墨黑与训练完成绿。角色不采用另一套霓虹游戏 UI；身体轮廓随训练阶段加宽，极高阶段允许夸张肌肉轮廓，但卡片、按钮和字体仍属于形域。

## 经验算法

经验只和用户自己的历史比较，不比较用户间绝对重量。

一次训练经验由以下部分组成，并全部设置上限：

- 有效训练基础经验：占比较低，防止刷无意义组。
- 同动作估算 1RM 提升：高权重，比较本次和历史同动作最佳表现。
- PR：高权重，按创造 PR 的动作数奖励。
- 计划完成：中等权重，完成原计划有效组获得奖励。
- 主观强度质量：产品此前已按要求从实时组录入中移除 RPE，因此第一版不虚构这一输入，也不因缺失惩罚；若未来重新提供可选主观强度，才启用合理区间奖励。
- 一致性：按近四周真实训练周数和连续训练奖励，设软上限。

同动作最佳表现用 `重量 × (1 + 次数 / 30)` 的 Epley 估算值比较，提升比例限制在合理范围，避免录入错误产生异常经验。无历史动作只给首次完成奖励，不假装它是力量提升。

肌群经验由动作主肌群和次肌群权重分配。主肌群约 70%，次肌群共享约 30%；无法可靠识别的动作归入耐力或核心的最低权重，不凭名称猜测过多部位。

## 角色与奖励

角色配置包含基础体型、肤色、发型、上衣、裤子、鞋和配饰。身体训练痕迹由训练等级和肌群等级派生，不是付费属性。外观可由训练、PR、连续训练、探索和成就解锁；未来付费只售外观，不出售 XP、PR 或能力。

## 世界与隐私

- 默认不出现在训练场。
- 用户主动开启后，选择或输入场馆代号；服务端不接收经纬度。
- 展示匿名昵称、训练部位、训练时长和等级，在线状态按短 TTL 自动过期。
- 互动只允许碰拳、加油和挑战，第一版不允许自由聊天。
- 所有互动可关闭；挑战只产生邀请，不改变 XP 或训练公平。
- 同一发送者对同一训练者的同类互动设 24 小时冷却，避免刷取同伴经验。

## 每日探索

每日任务按日期稳定生成，例如心形、圆形、三角形、对称图案和指定颜色。第一版允许用户选择照片并自行确认完成，明确标注“由你确认”，不宣称 AI 已验证。完成后获得探索 XP、收藏和少量外观货币；探索等级与训练等级分离。

## 状态与恢复

- 本地状态按账号隔离保存；升级、任务完成和装扮变更立即落盘。
- 训练结算采用幂等训练记录 ID，重复打开结算不会重复发放经验。
- 服务端训练场信息短期存储；断网时展示离线状态，不影响训练和结算。
- 文本缩放、减少动态效果和中英文界面继续沿用现有设置。

## 验收指标

- 首页 320–414px 宽度下“开始/继续训练”无需滚动即可识别且没有重复主 CTA。
- 无历史、首次训练、PR、力量提升、刷低质量组、缺失 RPE 均有确定且可测试的经验结果。
- 同一训练记录只能结算一次。
- 默认不上传位置或训练场状态；关闭展示后服务端在线记录立即失效。
- 世界为空时不显示虚构用户。
- 200% 文本缩放无关键按钮溢出，角色卡和结算页可滚动。
