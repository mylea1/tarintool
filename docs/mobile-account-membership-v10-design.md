# KILO 账号、会员与额度设计 v10

## 商业判断

目标用户是正在验证 KILO 的个人健身用户。当前替代方案是无账号的本地数据、人工发放测试权限和无法解释的功能失败。最小可用路径是“登录 -> 看见剩余额度 -> 使用功能 -> 兑换或完成训练获得额度”。这轮最可能影响登录后首次完成训练、AI 问答或动作识别的成功率。

## 前提与边界

1. 当前 `backend-mock` 没有生产数据库，Flutter 也没有持久化账号系统。本轮提供可测试的本地账号仓储和服务端契约边界，不声称具备生产安全性。
2. `1234 / 1234` 仅在 Debug 或显式测试开关下可用，拥有管理员权限。Release 包不得默认开放该账号。
3. 手机号、Apple、Google 登录都通过统一 provider 接口呈现。手机号测试登录可运行；Apple/Google 在缺少开发者凭据时显示“尚未配置”，不得伪造登录成功。
4. 正式发布前，登录令牌、会员到期时间、兑换码消费、额度扣减和管理员操作必须由服务端原子校验，客户端只展示服务端结果。

## 权益规则

### 免费用户

- AI 问答：每天 3 次，按设备本地日期重置。生产端改为服务端时区策略。
- 动作识别：注册赠送 5 次；每个自然周补充 1 次；完成一次有效训练奖励 1 次。
- 训练计划、训练记录和动作库保持可用，不用核心记录功能逼迫付费。

### 会员

- 兑换码支持 1 个月、3 个月、永久。
- AI 问答每天 20 次。
- 动作识别每周补充 3 次，仍可累积训练奖励。
- 解锁进阶统计、云同步/导出和会员主题的产品入口。高成本识别不做“无限”，避免个人开发阶段产生不可控 GPU 账单。

### 管理员

- Debug 测试账号：用户名 `1234`，密码 `1234`。
- 可按用户标识开通 1 个月、3 个月或永久会员。
- 可生成一次性兑换码，并查看类型、状态和创建时间。
- 所有操作在正式后端必须留审计记录；客户端本地管理员仅供当前测试。

## 信息架构

- 未登录：启动后进入登录页。主动作是手机号登录，Apple 只在 iOS 显示，Google 仅在海外功能开关开启后显示。
- “我的”首屏：紧凑账号卡展示身份、会员状态、AI 与识别剩余额度；兑换码是次级入口。
- 管理员工具：仅管理员在“我的”看到，进入完整页面，不把批量管理塞进普通用户界面。
- AI/动作识别：在执行前显示剩余额度；额度不足时给出可恢复路径，而不是静默禁用按钮。

## 状态与反馈

- 登录：加载、字段错误、账号不存在、服务未配置、成功状态齐全。
- 兑换：无效、已使用、成功、网络错误状态齐全；成功后即时刷新会员到期时间。
- 额度：每次扣减后显示剩余次数；完成训练奖励用短时成功条反馈并支持减少动态效果。
- 触控目标不小于 44dp，文本缩放 200% 时允许纵向增长，不使用固定高度承载动态文案。

## 正式后端接口边界

- `POST /v1/auth/phone/login`
- `POST /v1/auth/apple`
- `POST /v1/auth/google`
- `GET /v1/me/entitlements`
- `POST /v1/redemptions/redeem`
- `POST /v1/usage/consume`
- `POST /v1/rewards/workout-completed`
- `POST /v1/admin/memberships/grant`
- `POST /v1/admin/redemption-codes`

所有修改接口需要幂等键，管理员接口需要角色校验，兑换和额度扣减需要事务或原子条件更新。

## 验收标准

1. 首次启动未登录时显示登录页，`1234 / 1234` 在 Debug 可登录并进入主页。
2. 普通测试用户可通过手机号测试流程登录，退出后返回登录页。
3. “我的”显示账号、会员、AI 每日额度、识别额度和兑换码入口。
4. AI 成功发送前扣减额度，失败不扣；免费用户第 4 次被阻止并收到明确提示。
5. 新用户拥有 5 次识别额度；成功提交识别任务前扣减，失败回滚；每周补充规则可测试。
6. 完成有效训练最多奖励本次训练 1 次识别额度，重复打开总结不重复奖励。
7. 兑换码可授予 1 月、3 月、永久会员，同一码不可重复使用。
8. 管理员可为用户开通会员并生成兑换码；非管理员看不到入口且调用被拒绝。
9. Apple/Google 未配置时不伪造成功，给出配置提示。
10. Flutter analyze、测试和 debug APK 构建通过；Release 默认不开放 `1234 / 1234`。

## 后续付费方向

优先顺序：进阶趋势与训练报告、跨设备云同步与导出、教练共享、会员主题。主题可做低成本附加价值，但不应成为第一付费理由。暂不做广告、训练记录数量限制或基础动作库付费墙。
