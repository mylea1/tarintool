# KILO 计划重量与训练记录联动改版

日期：2026-08-04
规划：Sol
实现：Luna Worker
状态：已批准执行

## 用户问题

现有“新建计划”只产生一个模板壳，用户还要再次进入编辑器添加动作。计划编辑器把每个字段绘制成大型描边输入框，纵向高度过大；在 320 至 375px 手机和文本缩放环境下，动作与组数据很难扫读。历史详情虽然有每组数据，但缺少动作图片，也没有说明计划重量和实际重量的差异。顶部品牌标题区按文本缩放倍增高度，又在训练和 AI 页面下方叠加大型分段按钮，形成两个相互竞争的头部。

## 商业和任务判断

核心用户动作是“建立一节可执行训练，并在训练后理解是否按计划完成”。最可能提升的指标是新建计划完成率和训练记录复盘率。推动它们的设计分别是一次完成的计划编排器，以及计划重量到实际重量的可解释差值。

## 方案比较

### A. 继续沿用模板壳，自动打开编辑器

改动小，但会留下空模板和保存时序问题，计划重量仍然只是普通重量字段。

### B. 草稿式单页编排器与计划/实际双值模型（采用）

“新建计划”直接打开尚未写入列表的草稿编辑器。用户输入名称、添加动作、设置组别类型、计划重量、次数和休息，点击保存后才写入计划。开始训练时复制计划重量为本次实际重量，训练中修改的是实际重量，结束后记录同时保存两者。

### C. 独立训练计划数据库与版本系统

长期最完整，但当前本地原型没有持久化数据库，超出本轮验证需要。

## 数据契约

- `WorkoutSet.plannedWeight`：计划预期重量。
- `WorkoutSet.weight`：本次训练实际使用重量，保留现有字段以兼容训练量、计时和既有界面。
- 旧数据没有 `plannedWeight` 时，以 `weight` 回填。
- 计划编辑器修改计划重量时，同步计划模板的 `plannedWeight` 和初始 `weight`。
- 开始计划时，本次训练组的 `weight` 初始化为 `plannedWeight`。
- 训练中用户只修改 `weight`，不覆盖 `plannedWeight`。
- 训练完成记录保存两个值；训练量仍按实际重量计算。
- 记录和进步页面计算差值：`实际重量 - 计划重量`，并显示达成、低于或高于计划。

## 新建计划路径

```text
点击“新建计划”
  → 打开草稿编排器
  → 输入训练名称
  → 添加动作
  → 设置计划重量 / 次数 / 组别类型 / 休息
  → 保存计划
  → 写入“我的计划”列表并显示反馈
```

取消草稿不产生空计划。没有动作时保存按钮禁用，并解释“至少添加一个动作”。

## 计划查看与编辑

- 点击计划卡片主体进入只读详情，不直接开始，也不进入编辑状态。
- 详情显示动作图片、动作名、组数、计划重量范围、次数和休息。
- 详情底部保留一个主要操作“开始训练”，次要操作“编辑计划”。
- 卡片上的“开始”和“编辑”仍可保留为快捷动作，但卡片主体必须可查看详情。

## 紧凑计划编辑器

- 顶部：训练名称输入和动作数量，不再使用大号标题加额外元信息弹窗。
- 动作卡：图片、名称、组数/休息摘要；默认只展开当前编辑动作。
- 动作工具：上移、下移、替换、超级组、删除收进一行紧凑工具栏或更多菜单。
- 动作休息使用紧凑数值控件，不占整行大输入框。
- 每组采用两行结构：第一行组序号、组别类型、删除；第二行计划重量和次数。宽屏可合并为一行。
- 字段使用填充式紧凑输入，不使用截图中的大型描边框。
- 底部固定“保存计划”，并避开系统导航安全区。

## 记录与进步联动

- 历史列表为每条训练展示最多三张动作缩略图。
- 历史详情每个动作卡显示真实动作图片。
- 每组展示“计划 80.0 kg → 实际 82.5 kg”，以及次数、休息和组别类型。
- 进步弹窗增加“计划达成率”和“实际与计划差值”摘要；趋势图按实际训练量绘制。
- 没有计划重量的旧记录显示“计划重量未记录”，不伪造差值。

## 顶部导航融合

- 全局顶部栏取消副标题，只保留 KILO、当前页面标题和必要的右侧动作。
- 顶部高度固定为紧凑范围，不再乘以 `textScaler`；文本在 200% 时单行省略，页面内容本身仍支持缩放。
- 训练和 AI 的二级导航改为透明背景的文字标签与底部指示线，放在页面内容顶部，不再使用突出的整块 SegmentedButton。
- 训练中实时计时和休息状态仍有独立视觉优先级。

## 验收标准

- 新建计划一次进入动作编排器，取消不留下空计划，保存后动作和计划重量完整。
- 点击既有计划卡片打开只读详情，含动作图片和计划数据。
- 开始训练后实际重量可修改且不覆盖计划重量；结束记录同时保存两者。
- 历史列表/详情含动作图片；每组显示计划和实际重量以及休息。
- 进步弹窗显示计划达成率或计划差值，不再只显示孤立数字。
- 顶部栏明显变矮，训练/AI 标签融入页面，无双重厚重导航。
- 320、375、414px 与 200% 文本缩放下无 overflow、遮挡或不可达保存按钮。
- 原有 5 项底部导航、实时训练、锁屏通知、AI 和识别能力不回退。
- 新产物版本提升为 `1.0.2 (3)`，并输出唯一文件名 APK，避免再次安装错包。
