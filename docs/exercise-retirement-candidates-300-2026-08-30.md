# 冷门动作软删除清单（300 项）

> 生成日期：2026-08-30。编号是完整 catalog 中的稳定编号，软删除后不会重排。

## 怎样判定“冷门”

- 先保护项目手工筛选的基础动作，不进入候选。
- 稀有器械权重最高：训练锤、轮胎、滑雪机、波速球、雪橇、训练绳、泡沫轴等。
- 动作名包含单侧、交替、跪姿、转体、爆发、跳跃等过度细分特征时加分。
- 拉伸/热身、技术门槛高的抛掷与举重变式加分；常见力量模式减分。
- 分数只用于选出前 300 项，不冒充真实搜索量。若要用流量定标，需接入可审计的 Google Trends/站内搜索数据。

## 怎样删除且不破坏旧数据

1. `catalog` 仍保留全部动作，旧训练记录和旧计划仍能按 ID 解析。
2. 选择器和动作库只从 `selectableCatalog` 过滤这 300 个 ID。
3. 编号始终来自完整 `catalog` 的位置，因此用户后续报“删 425”不会因本次筛选而指向错动作。
