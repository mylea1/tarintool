# KILO 训练专注与强反馈 v9 设计

日期：2026-08-05

## 用户与商业判断

- 目标用户是在组间单手操作手机的力量训练者。最重要的任务不是浏览设置，而是快速找到动作、录入一组、理解剩余休息并继续训练。
- 当前替代方案是系统秒表、备忘录和抖音等视频平台来回切换。KILO 的价值是把记录和反馈连成一个不中断训练的流程。
- 最小采用路径是“选择计划或自由训练 → 添加动作 → 完成组 → 结束训练 → 查看总结”。
- 本轮最可能影响的指标是训练完成率、添加动作耗时、组间误操作率和次日回访率。
- 失败成本是辅助设置挤占首屏、计时信息重复、图标无法理解，以及完成训练后没有足够正反馈。

## 设计读取

移动端力量训练工具，面向组间单手快速操作；采用 Material 3 与 KILO 蓝色品牌，视觉密度 8/10、动效强度 7/10、布局变化 7/10。动效只服务状态反馈和训练总结，不添加循环装饰动画。

## 产品决策

### 动作详情

- 保留“概览 / 教学 / 记录”三个标签。
- 概览删除重复的“动作概览”和“最近完成组”区块；保留训练次数、最重重量和估算 1RM 三项真实指标。
- 备注与链接改为一个紧凑资源区，不再暴露动作库/本次训练/计划三套范围选择。底层旧数据结构保留，默认读写动作库范围，避免破坏已有数据。
- 支持保存备注和 HTTP/HTTPS 链接。点击链接交给系统处理：已安装且支持该链接的抖音等 App 可以直接打开，否则回退浏览器；KILO 不下载、不转存、不内嵌第三方视频。

### 实时训练

- 总训练时长与组间休息合并到一个紧凑计时控制区；实时训练时顶部不再重复显示休息计时胶囊。
- 暂停/恢复、批量、杠片、设置均使用“图标 + 文案”，而不是无标签图标。
- 休息状态进入同一卡片，提供“+15 秒”和“跳过”文字动作，减少重复卡片和垂直占用。

### 动作库与动作选择

- 左侧部位 rail 缩窄，右侧动作改为双列图片卡。
- 默认仅显示中文动作名，不在卡片中混排英文；搜索仍可匹配英文。
- 器械筛选收敛为紧凑入口；新增按钮明确使用白色加号和蓝色背景。
- “我的”增加“动作名称语言”，支持简体中文与 English。该设置只控制动作名称展示，避免把尚未完整本地化的整套界面伪装成英文版。

### 强反馈

- 完成一组继续使用整行绿色状态，并增加短促顶部粒子/光晕；支持系统减少动态效果。
- 通用成功提示升级为带成功图标的短反馈，但不让非主要提示长期占屏。
- 保存训练后展示全屏总结卡：训练时长、训练量、有效组、动作数和完成率，配一次性粒子动画与明确的“查看记录 / 完成”动作。
- 所有动画仅使用 transform/opacity 或 CustomPainter，避免影响滚动和录入性能。

## 响应式与可访问性

- 验证 320、375、414 px；关键控件触控目标不低于约 44 dp。
- 覆盖 200% 字体、超长动作名、长链接、大重量/次数、空记录和链接打开失败。
- 320 px 仍保持双列动作卡；文本允许两行省略，不产生水平溢出。
- 关闭动态效果时，粒子动画降级为静态成功卡和图标。

## 验收标准

1. 动作详情概览不存在“动作概览”“最近完成组”重复区块，备注/链接明显更紧凑。
2. HTTP/HTTPS 链接可保存、可点击，并有系统外部打开与失败反馈。
3. 实时训练只显示一个计时控制区，总时长与休息倒计时可同时理解。
4. 批量、杠片、设置和休息操作均有文字标签。
5. 动作库默认中文、双列卡片、窄 rail；添加按钮加号为白色。
6. “我的”可切换动作名称语言，切换后动作库、选择器和详情名称一致更新。
7. 保存训练后出现包含真实数据的总结卡和一次性完成特效。
8. 320/375/414、200% 字体与 reduced-motion 验收通过。
9. Flutter analyze、test、debug APK 构建通过；版本和唯一产物名递增。
