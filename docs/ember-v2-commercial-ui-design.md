# KILO Ember V2 商业化界面设计

## 目标

KILO 面向希望在训练现场快速记录、获得明确反馈，并持续回看进步的个人力量训练者。用户当前通常在 Hevy、训记、系统计时器和通用 AI 之间切换。此次改版不改变现有五项导航、数据模型、表单字段和关键测试标识，而是让核心路径更短、更有反馈。

核心路径：开始训练 -> 完成一组 -> 看清组间休息 -> 保存训练 -> 查看进步。

## 商业判断

这次设计最可能影响四个指标：主页开始训练率、实时训练组完成率、训练保存率、用户对会员价值的理解率。

- 主页只保留一个主训练动作，并把本周训练变成可扫描的数据带。
- 实时训练采用紧凑表格，完成一组后整行变绿并触发一次性庆祝反馈。
- “我的”从设置列表升级为账户中心，先展示身份、会员、额度和训练资产，再放偏好与系统设置。
- 低频管理功能和解释文案后置，管理员工具只对管理员显示。

## 前提

1. 暖橙是品牌行动色，不用于普通说明文字或大面积背景。
2. 训练数据语义、路由、测试 key 和现有控制器接口保持稳定。
3. 大胆变化来自信息形态、层级和反馈，而不是增加装饰。
4. Hevy 和训记只用于理解成熟训练产品的密度与路径，不复制其受保护的视觉资产或页面。

## 方案比较

### A. 只替换主题 token

改动最小，但无法解决卡片堆叠、个人页缺少价值层级和实时训练控制区过大的问题。

### B. 共享 Ember 设计系统并重构关键页面（已选择）

统一颜色、圆角、阴影、按钮和状态语义；重点重构主页、训练计时控制台和“我的”，让动作与 AI 继承新组件。它保留业务契约，同时能产生明显的产品升级。

### C. 全量重写所有页面

视觉自由度最高，但会扩大回归范围，容易破坏已有训练、记录、会员和识别流程，不适合当前验证阶段。

## 页面变化

### 主页

今日训练采用单一主面板；本周进度改成表格化日期带；进步摘要使用真实数据的迷你趋势与指标，不再只显示孤立数字。

### 训练

总计时和休息信息整合为一个紧凑控制台。组表格保留“组、上次、kg、次数、RPE、完成”，完成行同时使用绿色底、绿色边界、实心勾和成功提示。

### 动作

保留左侧部位 rail 和双列动作卡。图片占比提升，器械与部位降为次级信息，搜索与筛选合并为一条紧凑工具行。

### AI

保留问答与识别顶部切换。答案中的来源改为可点击的证据区，识别入口使用单一报告动作，避免设置抢占主区域。

### 我的

首屏顺序为：身份与会员 -> AI/识别额度 -> 训练资产 -> 个性化快捷设置 -> 服务与安全 -> 管理员工具。会员信息有明确状态和兑换入口，设置不再和商业信息混在同一层级。

## 验收

- 320、375、414、768、1024、1440 宽度无水平滚动。
- 200% 文本缩放下关键按钮可用，长用户名和长计划名不会挤出容器。
- 所有主要按钮有按下、禁用、加载或成功反馈。
- 训练完成状态不只依赖颜色。
- `flutter analyze` 与 `flutter test` 通过。
